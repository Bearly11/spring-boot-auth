## 📝 ការពិពណ៌នា (Description)
នេះគឺជាប្រព័ន្ធ Backend សម្រាប់គ្រប់គ្រងការផ្ទៀងផ្ទាត់សិទ្ធិ (Authentication) ដែលបង្កើតឡើងដោយប្រើ **Spring Boot** និង **Spring Security**។ គម្រោងនេះផ្ដោតលើការអនុវត្តស្ដង់ដារសុវត្ថិភាពក្នុងការគ្រប់គ្រងអ្នកប្រើប្រាស់ និងការការពារ API Endpoints។

## ✨ លក្ខណៈពិសេស (Key Features)
* **User Registration & Login:** ប្រព័ន្ធចុះឈ្មោះ និងចូលប្រើប្រាស់ដោយសុវត្ថិភាព។
* **Spring Security Integration:** ប្រើប្រាស់ Filter Chain ដើម្បីគ្រប់គ្រងសិទ្ធិចូលប្រើប្រាស់។
* **Role-Based Access Control (RBAC):** បែងចែកសិទ្ធិរវាង `ADMIN` និង `USER` (Protect Routes)។
* **Password Encoding:** ប្រើប្រាស់ **BCrypt** ដើម្បីធ្វើការ Encrypt លេខសម្ងាត់មុននឹងរក្សាទុកក្នុង Database។
* **Database Management:** ប្រើប្រាស់ **PostgreSQL** ជាមធ្យោបាយរក្សាទុកទិន្នន័យ។

## 🛠 បច្ចេកវិទ្យា (Tech Stack)
* **Framework:** Spring Boot (Data JPA, Security, Web)
* **Language:** Java 17
* **Database:** PostgreSQL
* **Security Tool:** Spring Security, BCrypt Password Encoder
* **Build Tool:** Maven
